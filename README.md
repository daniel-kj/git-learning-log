![Image](https://nextwork.ai/lively_turquoise_clever_feijoa/uploads/8bf3bcb5-a70d-418a-9c76-251365f69028_drz4zcda)

### Why merge conflicts occur

A merge conflict happens because I made changes to  the same lines  so when I attempt to merge both branches git won't know which one to keep.

![Image](https://nextwork.ai/lively_turquoise_clever_feijoa/uploads/8bf3bcb5-a70d-418a-9c76-251365f69028_0e34g9cu)

### Interpreting Git conflict markers

The conflict markers show me the lines I need to change to resolve the conflict. The HEAD section contains the lines from the main brach. The other section contains lines from the merging branch.
